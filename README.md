# 🔐 Network Packet Sniffer

A Python tool that captures and analyzes live network packets using Scapy.

## 🛠️ Tech Used
- Python 3
- Scapy

## ⚙️ Installation
```bash
pip install -r requirements.txt
```

## ▶️ Usage
```bash
# Windows (Run as Administrator)
python sniffer.py

# Linux/Mac
sudo python3 sniffer.py
```
